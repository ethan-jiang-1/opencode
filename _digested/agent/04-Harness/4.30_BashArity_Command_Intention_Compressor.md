# 4.30 `BashArity`：命令意图前缀压缩器

## 源码是什么 (Source)
- `packages/opencode/src/permission/arity.ts`
- 协同调用：
  - `packages/opencode/src/tool/bash.ts` (`BashArity.prefix(tokens)`)
- 关键符号：
  - `prefix(tokens)`
  - `ARITY` 命令前缀字典（如 `git`, `npm run`, `docker compose`）

## 解读是什么 (Interpretation)
`BashArity` 解决的是“bash 授权项粒度”问题。

1. 最长匹配优先
- `prefix(tokens)` 从最长前缀向下查 `ARITY`，命中后按 arity 截取命令意图。
- 例如 `npm run dev -- --watch` 会归到 `npm run dev`（arity 3）。

2. 未命中字典时保守降级
- 空 token -> `[]`
- 其他 -> 默认只取首 token（如 `python script.py` -> `python`）

3. 目的不是执行，而是权限表达稳定化
- 在 `bash.collect(...)` 中生成 `always` 模式：`<prefix> *`
- 用于长期 allow 规则，减少每次审批噪音。

## implication 是什么 (Harness Implication)
- 如果没有 `BashArity`，长期授权会过于细碎或过宽，难以复用。
- 你可以通过扩充 `ARITY` 来适配公司自定义 CLI 生态，提高授权命中率。
- 这是“命令语义压缩层”，在权限系统里比字符串全文匹配更可维护。
