# 4.1 事件钩子与强力拦截实战 (Interceptor Hooks)

到了本手册第四篇章，我们终于迈入了这套机制最具扩展性、最让极客激动的模块——如何把公司特定的私有上下文和业务环境强力装配给这台引擎。

OpenCode 给出的解法，不是提供一个输入框让你疯狂拼字，而是给你最深度的 **Plugin Hooks (钩子)**，这是任何大型现代化 Node 框架必备的核心设计武器。

## 🪝 我们在哪可以挂起吊钩？

翻阅 `packages/opencode/src/session/prompt.ts`，你可以清楚地看到有两个可以作为发力点的原生插件发射事件：

1. `experimental.chat.messages.transform`：它暴露给你的是**即将发给大模型的上万字对话流 (msgs)**。
2. `experimental.chat.system.transform` / `command.execute.before`：这是拼凑 **System Prompt** 的组装线上流转前的节点。

有了这些，你可以编写特定的 `Plugin`（遵循 OpenCode 插件架构机制的中间件），做无数的事情。下面给出一种高阶构想及技术层面的伪型设计 (Snippets 设计理念)。

## 💡 实战假想：外挂企业内部架构规范 RAG

假设我们需要系统性赋予 Agent 超凡脱俗的开发能力，例如：“永远依照我们团队内部上周刚定稿的代码规约，但规约足足有 20 万字的 Markdown 文件存储在某个在线知识库中。”

### 场景推敲 (Design Process)
❌ **初级玩家的做法**：每次启动提问前，要求模型连上知识库或者在配置文件里复制大片文字。很不幸，因为上个章节提到的 `Compaction`，几轮对话之后，你的企业规范就被大模型洗忘（遗忘）殆尽了。

✅ **Harness 架构师的做法：在生命周期的底层做隐形截留。**

我们可以写一段逻辑向 `Plugin.trigger("experimental.chat.messages.transform")` 注册：

```typescript
// 伪架构逻辑演示 (Pseudo-Implementation)
Plugin.registerHook("experimental.chat.messages.transform", async (payload, context) => {
    // 1. context.messages 就是即将打向大模型的历史数组
    
    // 2. 利用轻量级本地分类器，探测当前最末尾 User 消息意图
    const lastUserQuery = context.messages.findLast(m => m.info.role === "user");
    
    // 3. 将 User 需求打成 Embedding 请求内部高维向量数据库（RAG 检索）
    const rules = await companyVectorDb.search(lastUserQuery.text);
    
    if (rules.length > 0) {
        // 4. 重头戏！我们不用修改用户的原始消息。
        // 我们在 context.messages 最临近发送前的地方，硬性插入（Unshift）一个
        // synthetic (人工合成、且在控制台隐藏) 的幽灵报文！
        context.messages.push({
            info: { role: "user", synthetic: true, ... },
            parts: [{
                type: "text", 
                text: `<system_critical_context>\nBased on search, you MUST follow these internal rules: \n${rules}\n</system_critical_context>`
            }]
        });
    }
});
```

### 收获了什么？
- **零成本的极致专注**。LLM 对此并不知情，它只觉得自己是在与你对话的中途，突然被天降的一阵知识打断了，而这些知识精确锚向你此时此刻输入的需求片段。
- **UI 脱敏**。因为 `synthetic: true` 机制，坐在终端或 Web 页面前的开发者根本看不到这个钩子注入的上万字检索结果。他看到的只是：Agent 在看到一句“帮我写个登陆组件”的极短指令后，流畅地写出了拥有公司标志性注解和标准样板间风格的全部 React 代码。

这，才是使用 Effect 环境和立体 Message 给大型 Agent 搭建骨骼护甲的顶级快乐。
