# 4.20 Plugin Config Patcher：JSONC 安全补丁与去重替换策略

## 源码是什么 (Source)
- `packages/opencode/src/plugin/install.ts`
- 关键符号：
  - `installPlugin(...)`
  - `readPluginManifest(...)` (`oc-plugin` targets)
  - `patchPluginConfig(...)`
  - `patchPluginList(...)` + `jsonc-parser modify/applyEdits`

## 解读是什么 (Interpretation)
这层负责“把插件写进配置文件”，并处理真实世界的脏 JSONC：

1. manifest 驱动 target
- 从插件包 `oc-plugin` 读取目标（server/tui + opts）。

2. 配置补丁支持 JSONC
- 用 `jsonc-parser` 解析/修改，保留注释与格式风格。

3. 插件列表去重逻辑不是按字符串，而是按包名
- 同 spec 命中或同 npm package 命中都算重复。
- `force` 时可替换并清除重复项，否则 noop。

4. patch 过程有细粒度错误码
- `invalid_json`（含行列与 parse error code）
- `patch_failed`

5. 写配置前有文件锁
- `Flock.acquire(...)` 防并发 CLI 同时改配置导致竞争损坏。

## implication 是什么 (Harness Implication)
- 配置补丁层是平台级能力，建议所有自动安装流程复用，不要手写字符串拼接。
- “按包名替换”减少重复插件污染，但也意味着 rename 包名会触发并存，需要治理策略。
- JSONC 保真修改 + 文件锁，是让自动化可放心上线的基础。
