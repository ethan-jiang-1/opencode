# 4.25 `resolvePromptParts`：Markdown 引用展开器

## 源码是什么 (Source)
- `packages/opencode/src/session/prompt.ts`
- 协同源码：
  - `packages/opencode/src/config/markdown.ts`
- 关键符号：
  - `SessionPrompt.resolvePromptParts(template)`
  - `ConfigMarkdown.files(...)`（`@path` 抽取）
  - `pathToFileURL(...)`
  - `Agent.get(name)` fallback

## 解读是什么 (Interpretation)
这层把“自然语言模板”预编译成结构化 `parts`。

1. 从文本里抽取 `@...` 引用
- 通过 `ConfigMarkdown.FILE_REGEX` 找到文件或目录引用。
- 去重处理同名引用，避免重复注入。

2. 路径解析支持 workspace 与 home
- `~/...` 解析到用户 home。
- 其他相对路径解析到 `Instance.worktree`。

3. 文件不存在时会尝试解释为 agent 名称
- 若 `stat` 失败但命中 agent，则转成 `{ type: "agent", name }` part。

4. 生成的 file part 带标准 URL 和 MIME
- 文件/目录都转为 `file://` URL。
- 目录 MIME 设为 `application/x-directory`。

## implication 是什么 (Harness Implication)
- 这是命令模板与 prompt DSL 的“编译前端”，可让输入协议从纯文本升级到结构化多 part。
- `@xxx` 既可引用路径也可指向 agent，为命令系统提供了统一表达面。
- 想扩展模板语法，应优先在这一层做解析，不要散落到后续运行阶段。
