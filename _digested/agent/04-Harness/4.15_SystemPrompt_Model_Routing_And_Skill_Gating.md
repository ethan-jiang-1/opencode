# 4.15 SystemPrompt：模型路由与 Skill 能力门控

## 源码是什么 (Source)
- `packages/opencode/src/session/system.ts`
- 关键符号：
  - `SystemPrompt.provider(model)`
  - `SystemPrompt.environment(model)`
  - `SystemPrompt.skills(agent)`

## 解读是什么 (Interpretation)
SystemPrompt 层解决的是“给谁喂哪种系统提示”：

1. provider 路由是显式规则
- GPT-4/o1/o3 -> `beast`
- GPT Codex -> `codex`
- 其他 GPT -> `gpt`
- Gemini -> `gemini`
- Claude -> `anthropic`
- Trinity -> `trinity`
- 默认 `default`

2. environment 是可观测环境块
- 注入 cwd/worktree/vcs/platform/date 等运行环境信息。
- 包含 `<directories>` 栏位（当前实现默认未展开树）。

3. skills 注入受权限门控
- 若 `skill` 工具被 permission 禁用，则不注入 skills 提示。
- 否则注入可用 skills 列表（verbose 格式）引导模型调用。

## implication 是什么 (Harness Implication)
- 这是“prompt 分发器”，新增模型族时应优先在此加路由，而不是散落各处。
- skill 门控意味着权限不仅约束执行，还会反馈到认知层（模型是否知道 skill 的存在）。
- 你可以用这层做最小可控的环境暴露，平衡可用性与信息泄露。
