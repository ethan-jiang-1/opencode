# 4.14 InstructionPrompt：邻域继承与单消息去重注入

## 源码是什么 (Source)
- `packages/opencode/src/session/instruction.ts`
- 关键符号：
  - `systemPaths()`, `system()`
  - `loaded(messages)`
  - `resolve(messages, filepath, messageID)`
  - `claims` (`isClaimed/claim/clear`)

## 解读是什么 (Interpretation)
InstructionPrompt 有两条注入路径：全局系统指令 + 文件邻域指令。

1. systemPaths 会汇总多来源
- 项目内 `AGENTS.md/CLAUDE.md/CONTEXT.md`
- 全局 `~/.config/.../AGENTS.md` 或 `~/.claude/CLAUDE.md`
- `config.instructions`（支持本地路径与 URL）

2. system() 会读取本地并拉取远端
- 本地 instruction 文件全部拼进系统 prompt。
- URL 指令做 5 秒超时 fetch。

3. loaded(messages) 利用 read 工具 metadata 去重
- 从历史 `read` 工具结果 metadata.loaded 找到已注入指令路径，避免重复灌入。

4. resolve(...) 做“目标文件向上爬目录”的邻域继承
- 从目标文件所在目录向上扫描到 workspace root。
- 找到附近 AGENTS/CLAUDE 等文件后注入。
- 同时用 `claims(messageID)` 保证同一消息轮次只注一次。

## implication 是什么 (Harness Implication)
- 这是一个“上下文继承系统”，可把局部规范自动附着到具体文件操作上。
- claim 机制很关键：没有它会出现同轮重复注入，迅速膨胀 token。
- 若你要加公司私有规则层，优先扩展 instruction source，而不是在 prompt 文本里硬拼。
