# 4.27 StructuredOutput：JSON Schema 强制出口通道

## 源码是什么 (Source)
- `packages/opencode/src/session/prompt.ts`
- 关键符号：
  - `createStructuredOutputTool({ schema, onSuccess })`
  - `STRUCTURED_OUTPUT_SYSTEM_PROMPT`
  - `toolChoice: "required"`（当 `format.type==="json_schema"`）
  - `handle.message.structured = structured`
  - `MessageV2.StructuredOutputError`

## 解读是什么 (Interpretation)
当用户要求结构化输出时，系统会把“文本回答”改造为“工具返回”。

1. 运行前强制注入结构化系统指令
- 在 system prompt 加入 `STRUCTURED_OUTPUT_SYSTEM_PROMPT`，明确禁止纯文本终答。

2. 动态注册 `StructuredOutput` 工具
- input schema 来自用户传入 JSON schema（去掉 `$schema` 字段）。
- tool execute 成功时通过 `onSuccess` 回传结构化对象。

3. 推理阶段强制工具选择
- `toolChoice` 设为 `"required"`，要求模型最终必须调用工具。

4. 成功路径会写 structured 字段并提前结束循环
- 捕获到 structured 后写入 assistant message，并 `break`。

5. 失败路径显式报错
- 若模型结束但没产出 structured，写 `StructuredOutputError`，而不是默默退回文本。

## implication 是什么 (Harness Implication)
- 这是把“输出格式约束”从软提示升级为协议约束的关键模式。
- 面向 API 集成时，可依赖 `structured` 字段做强类型消费，不必再后处理 JSON 解析。
- 若要扩展 XML/DSL 等结构化出口，可复用“专用工具 + required toolChoice”模式。
