# 4.2 Skill：静态知识包与按需装载

## 源码是什么 (Source)
- `packages/opencode/src/skill/index.ts`
- 协同源码：
  - `packages/opencode/src/tool/skill.ts`
  - `packages/opencode/src/session/system.ts`
- 关键符号：
  - `Skill.scan/loadSkills/available/get`
  - `SystemPrompt.skills(...)`
  - `SkillTool.execute(...)`
  - `Permission.evaluate("skill", ...)`

## 解读是什么 (Interpretation)
Skill 机制由“发现层 + 提示层 + 工具层”组成，不是单一 markdown 拼接。

1. 发现层支持多来源
- 扫描全局目录（如 `.claude/.agents`）、项目目录、配置 paths、远程 urls 拉取目录。
- 统一解析 `SKILL.md` 前置元数据为 `name/description/content`。

2. 提示层给模型“可用技能目录”
- `SystemPrompt.skills` 把可用 skill 列表放进系统提示，告诉模型可以调用 `skill` 工具。
- 同时受 permission 规则约束（可被禁用或筛掉）。

3. 工具层按需加载全文
- `skill` 工具执行时读取指定技能，经过 permission ask 后返回 `<skill_content ...>`。
- 输出包含技能基目录与文件采样，便于后续脚本/参考文件定位。

## implication 是什么 (Harness Implication)
- Skill 是低成本注入团队规范的首选，适合稳定流程与规则。
- 大体量指南不应默认常驻上下文，改为“目录常驻 + 按需加载”。
- 权限层可以把 skill 当作受控能力，而非无条件注入。
