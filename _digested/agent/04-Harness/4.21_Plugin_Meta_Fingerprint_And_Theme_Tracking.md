# 4.21 Plugin Meta：指纹追踪与主题资源注册

## 源码是什么 (Source)
- `packages/opencode/src/plugin/meta.ts`
- 关键符号：
  - `touch/touchMany/list/setTheme`
  - `fingerprint(core)`（file: target+mtime, npm: target+requested+version）
  - `State = first | updated | same`

## 解读是什么 (Interpretation)
PluginMeta 不是运行必需层，而是插件运营观测层：

1. 每次加载都会 touch 元数据
- 记录 `first_time/last_time/load_count/time_changed`。

2. 用 fingerprint 判断插件是否变化
- path plugin 看文件修改时间。
- npm plugin 看目标路径 + 请求版本 + 实际版本。

3. 有主题资源注册位
- `setTheme(id, name, theme)` 可挂插件导出的主题文件信息（src/dest/mtime/size）。

4. 存储有并发锁
- 使用 `Flock.withLock(...)` 保护 `plugin-meta.json`。

## implication 是什么 (Harness Implication)
- 这是做插件健康监控、变更审计和 UI 展示（最近更新插件）的基础数据源。
- fingerprint 策略决定“更新判定灵敏度”，若未来支持远端插件签名可在此扩展。
- 主题追踪位说明插件系统已经超出“逻辑 hook”，在往完整生态演进。
