# 3.9 Truncate：大输出落盘、提示文案与生命周期清理

## 源码是什么 (Source)
- `packages/opencode/src/tool/truncate.ts`
- 关键符号：
  - `MAX_LINES / MAX_BYTES / TRUNCATION_DIR`
  - `output(text, options, agent?)`
  - `hasTaskTool(agent)`
  - `cleanup()` + `RETENTION = 7 days`

## 解读是什么 (Interpretation)
Truncate 是“内容裁剪 + 全量落盘”的双轨系统。

1. 裁剪触发看两条阈值
- 行数超限或字节超限任一成立，就进入截断分支。
- 支持 `direction=head|tail`，可保留前段或后段。

2. 截断后仍保留全量文本
- 会把完整输出写入 `TRUNCATION_DIR/tool_*` 文件。
- 返回给模型的是 preview + “已截断”提示 + 落盘路径。

3. 提示文案会根据 agent 权限调整
- 若 agent 可用 `task`，提示优先委托子 agent 处理大文件。
- 否则提示用 `grep` 或 `read offset/limit` 手工定位。

4. 截断目录有后台 GC
- 启动后定时清理，删除超过 7 天的旧输出文件。

## implication 是什么 (Harness Implication)
- 这层把“上下文预算控制”和“可追溯原文保留”同时满足，是长任务稳定性的关键。
- 任务委托提示是策略化 prompt 工程，能主动引导模型节省上下文。
- 任何高噪声工具都应复用该层，而不是各自手写截断逻辑。
