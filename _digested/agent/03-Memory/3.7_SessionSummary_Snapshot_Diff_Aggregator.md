# 3.7 SessionSummary：基于快照边界的差异聚合器

## 源码是什么 (Source)
- `packages/opencode/src/session/summary.ts`
- 关键符号：
  - `summarize(...)`
  - `computeDiff({ messages })`
  - `summarizeSession(...)`, `summarizeMessage(...)`
  - `diff(sessionID)` 与 `unquoteGitPath(...)`

## 解读是什么 (Interpretation)
这层不是“文本摘要”，而是“文件改动摘要”：

1. 差异来源依赖 `step-start/step-finish` 快照
- `computeDiff` 扫描消息 parts，找最早 from 与最新 to 快照。
- 用 `Snapshot.diffFull(from, to)` 得到文件级增删统计。

2. session 级与 message 级双写
- session 级：总 additions/deletions/files + 落盘 `session_diff`。
- message 级：把 diffs 挂到对应 user message 的 `summary.diffs`。

3. 存储与总线协同
- 写 `Storage["session_diff"]`。
- 发布 `Session.Event.Diff`，让外界实时感知变更规模。

4. git path 兼容处理
- `diff(...)` 读取时会做 `unquoteGitPath`，处理 Git 风格转义路径。

## implication 是什么 (Harness Implication)
- 如果你要做“本轮都改了什么”视图，应直接复用 `session_diff`，不要二次跑 git diff。
- 快照边界机制意味着：没有 step 快照时 diff 为空，这不是 bug，而是数据契约。
- message 级 diffs 能支持“逐轮贡献回放”，适合 review/审计流水线。
