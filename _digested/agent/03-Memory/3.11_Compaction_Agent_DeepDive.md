## 源码是什么 (Source)

- 关键符号：
  - `defaultPrompt`
  - `plugin.trigger("experimental.session.compacting", ...)`
  - `processCompaction(...)`

## 解读是什么 (Interpretation)
这里关注 3.1 未展开的两个点。

1. 摘要提示词并非硬编码不可改
- 系统有默认模板（Goal/Instructions/Discoveries/Accomplished/Relevant files）。
- 但可以通过 `experimental.session.compacting` 注入 context 或替换 prompt。

2. 压缩后续跑有两种回注策略
- replay 模式：重建 user 消息并回放关键内容（媒体转占位文本）。
- continue 模式：写 synthetic 提示让主循环继续。

## implication 是什么 (Harness Implication)
- 这层 hook 让 compaction 可按组织规范定制（审计字段、任务模板、知识边界）。
- 如果你要做严格流程化交付，建议在该 hook 中固定摘要结构和术语。
