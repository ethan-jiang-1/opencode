# 2.12 自动标题生成：首轮单次摘要命名器

## 源码是什么 (Source)
- `packages/opencode/src/session/prompt.ts`
- 关键符号：
  - `title({ session, history, providerID, modelID })`
  - `Session.isDefaultTitle(...)`
  - `agents.get("title")`
  - `LLM.stream({ small: true, ... })`
  - `sessions.setTitle(...)`

## 解读是什么 (Interpretation)
标题生成是一个严格受限的“首轮副任务”。

1. 触发条件非常窄
- 仅根会话（非 `parentID`）。
- 当前仍是默认标题。
- 历史里“真实 user 消息”恰好只有一条。

2. 生成过程异步且轻量
- 在 runLoop 第一步时 fork 执行，不阻塞主回答。
- 优先使用 title agent 指定模型；否则回退 small model/当前模型。

3. 输入上下文有分支策略
- 若首条 user 仅由 subtask parts 构成，则只喂 subtask prompt 聚合文本。
- 否则走 `MessageV2.toModelMessages(context, mdl)`。

4. 输出有清洗与裁剪
- 去除 `<think>...</think>` 段。
- 取首个非空行，最长 100 字符（超长截断）。

## implication 是什么 (Harness Implication)
- 这是“非关键路径异步 enrich”模式，适合承载不影响主链路的体验增强功能。
- 严格触发条件避免标题反复抖动，保证会话命名稳定性。
- 若要扩展自动摘要类功能，可复用同样的 fork + guard 策略。
