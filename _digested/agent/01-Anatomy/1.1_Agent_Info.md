# 1.1 Agent 基座：`Agent.Info` 与内建角色集

## 源码是什么 (Source)
- `packages/opencode/src/agent/agent.ts`
- 协同源码：
  - `packages/opencode/src/permission/index.ts`
- 关键符号：
  - `Agent.Info` schema
  - 内建 agents：`build/plan/general/explore/compaction/title/summary`
  - `Permission.merge(...)`
  - `defaultAgent()`

## 解读是什么 (Interpretation)
`Agent.Info` 是运行时角色的结构化定义，不是纯 prompt 文本。

1. 角色字段是完整执行配置
- 包含 `mode/hidden/permission/model/prompt/options/steps`。
- 这让“同一个模型”可以在不同 agent 名下呈现不同执行边界。

2. 内建角色是分工化设计
- `build/plan` 是主代理；`general/explore` 是子代理。
- `compaction/title/summary` 是隐藏角色，承担后台专项任务。

3. 权限是合并链而非单点配置
- 基础 defaults + 系统专项规则 + 用户配置逐层 merge。
- `explore` 默认强约束（大量 deny + 只读/检索 allow）。

4. 默认代理有可见性校验
- `defaultAgent()` 会拒绝 subagent 或 hidden 作为默认入口。

## implication 是什么 (Harness Implication)
- 自定义 agent 最稳妥做法是“改配置对象”，不是堆 prompt。
- 要实现可靠的角色分工，应先定 `permission/mode/steps`，再定 `prompt`。
- hidden agent 是后台流水线能力（压缩/摘要/命名）的关键实现点。
